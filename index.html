🍕 PZaaS - Microsserviço: Forno

Documentação da arquitetura de processamento do forno de Lucas Gama

Este microsserviço atua como um processador de estado controlado no ecossistema PZaaS. Ele absorve requisições, gerencia a capacidade da fila via Redis, aplica a simulação térmica de 15 segundos e roteia o pedido finalizado suportando condições de rede instáveis através de Fallbacks.

Redis Fallbacks (Fila e Logger)
GET https://pzaas.online/webhook/v1/forno/gama/health

Monitoramento (Health Check)

Rota leve utilizada pelo Orquestrador para verificar a disponibilidade do serviço do Forno antes do envio de tráfego pesado.

Headers Obrigatórios

Chave Tipo Descrição
x-api-key String Chave de autenticação (Ex: turma2026).

Resposta da API

200 OK - Serviço online e pronto para receber requisições.

{
  "status": "OK",
  "servico": "Forno"
}
POST https://pzaas.online/webhook/v1/forno/gama

Processamento do Pedido

Recebe a pizza crua, valida a integridade do contrato, testa a resiliência via Chaos Monkey, aloca espaço no banco de dados e repassa para o Serviço 07 (Fila de Produção).

Headers Obrigatórios

Chave Tipo Descrição
x-api-key String Autenticação do sistema. Retorna Erro 401 se ausente.
x-pedido-id String Rastreio global de observabilidade. Retorna Erro 400 se ausente.
Content-Type String Deve ser restrito a application/json.

Corpo da Requisição (Body)

Validação estrita exigindo os identificadores do pedido e da pizza para garantir a rastreabilidade (Erro 400 em caso de divergência).

{
  "pedidoId": "PED-999",
  "pizzaId": "PIZ-888",
  "sabor": "Calabresa"
}

Matriz de Respostas HTTP

200 OK - Caminho Feliz.

Pizza validada, processada no Redis, assada por 15s e roteada para a fila de produção e logger com sucesso.

{
  "mensagem": "Pizza processada e enviada para a fila"
}

400 Bad Request - Contrato Quebrado.

Disparado por falha na validação do payload ou ausência do header de rastreio.

{
  "erro": "Dados da pizza invalidos"
}

401 Unauthorized - Falha de Segurança.

Conexão abortada imediatamente para proteger a camada do banco de dados.

{
  "erro": "Chave invalida"
}

500 Internal Server Error - Chaos Monkey.

Acionado quando a injeção de falha programada atinge o limite de tentativas de retry.

{
  "erro": "Falha interna no serviço devido a instabilidade",
  "detalhes": "timeout_ou_erro"
}

503 Service Unavailable - Forno Cheio.

Proteção contra sobrecarga de memória (Redis). Retorna tempo dinâmico para nova tentativa.

{
  "erro": "Forno sem capacidade no momento",
  "tente_novamente_em_segundos": 12
}
